# ASTRA FRONTIER — 3D Combat Demo

Upload `index.html` to any static web host to run the playable browser demo.

Controls:
- Desktop: WASD, mouse, left click/Space
- Mobile: touch/drag and tap the right side to fire

The demo uses Three.js from a public CDN, so internet access is required when loading the game.

This is a prototype/demo foundation, not the final commercial game build.
